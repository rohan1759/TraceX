# Evaluation Dataset for Face Matching

This directory holds test identity folders used by `scripts/evaluate_matching.py` to evaluate the ArcFace cosine distance threshold, True Match Rate (TMR), False Match Rate (FMR), and overall classification accuracy.

---

## Directory Structure

Organize images into individual subfolders named after each person:

```text
eval_data/
├── README.md
├── evaluation_results.csv        # Auto-generated by evaluate_matching.py
├── evaluation_plot.png           # Auto-generated by evaluate_matching.py
├── person_1/
│   ├── photo_1.jpg
│   ├── photo_2.jpg
│   └── photo_3.jpg
├── person_2/
│   ├── photo_1.jpg
│   └── photo_2.jpg
└── ...
```

---

## Guidelines for Adding Evaluation Images

1. **Number of Identities:**
   - Add **10 to 15 different individuals** for a statistically meaningful benchmark.
2. **Photos per Person:**
   - Provide **2 to 4 photos per individual**.
3. **Variation:**
   - Include diverse real-world conditions:
     - Frontal and slight angle views ($< 30^\circ$ yaw/pitch).
     - Varied lighting (indoor warm, daylight, outdoor, backlighting).
     - Natural facial expressions (smiling, neutral).
     - Accessories where possible (glasses, different hairstyles).
4. **Supported Formats:**
   - `.jpg`, `.jpeg`, `.png`.
   - Ensure resolutions are at least $120 \times 120$ pixels for reliable facial landmark detection.

---

## Running Evaluation

Run the evaluation script from the project root:

```bash
python scripts/evaluate_matching.py
```

Optional arguments:
```bash
python scripts/evaluate_matching.py --data-dir eval_data --csv eval_data/evaluation_results.csv --plot eval_data/evaluation_plot.png
```

The script will:
- Compute 512-d embeddings for all detected faces.
- Construct all same-person (positive) and different-person (negative) pairs.
- Sweep distance thresholds from $0.10$ to $0.90$.
- Output the optimal threshold maximizing accuracy and F1-score.
- Generate a summary CSV and visualization curves (`evaluation_plot.png`).
